隐私政策

适用于 shanxz1982.github.io/my-games-site 及同域相关页面。最近更新：2026-10-15。

1. 概述

本站是个人自制的纯静态小游戏合集。本政策说明我们如何处理与本站相关的信息。本站不要求注册账号，也不主动收集姓名、身份证号等个人身份信息。

2. 浏览器本地存储

部分游戏会使用浏览器的 localStorage（或同类本地存储）保存进度、设置、昵称或本机排行等数据。这些数据保存在你的设备上，不会由本站服务器代管（本站无自有后端）。清除浏览器站点数据即可删除。

3. Firebase（可选云功能）

若你使用带云同步 / 排行榜 / 联网房间等功能，本站可能通过 Google Firebase（例如 Firestore）读写公开或半公开的游戏记录（如分数、房间状态、你自行填写的昵称）。请勿在昵称或可写入字段中填写真实姓名、电话、住址等敏感信息。

4. Google AdSense 与 Cookie

本站使用 Google AdSense 展示广告。Google 及其合作伙伴可能使用 Cookie 或类似技术，根据你的访问情况投放广告、衡量效果，或提供个性化广告（取决于你的设置与所在地区法规）。

  • 你可以访问 Google 广告设置 管理个性化广告。
  • 了解 Google 如何使用数据，请参阅 Google 如何使用合作网站上的信息 与 Google 隐私权政策。

5. 日志与第三方

托管方（例如 GitHub Pages）或内容分发网络可能自动记录标准访问日志（如 IP、User-Agent、访问时间）。本站运营者不会把这些日志用于识别你的身份，也不出售个人数据。除本政策所述服务（AdSense、Firebase/Google）外，本站不嵌入其他追踪脚本。

6. 儿童

本站面向一般娱乐用户。若你是监护人，并认为未成年人通过本站向第三方服务提交了不当信息，请联系我们处理可及范围内的内容。

7. 政策变更

我们可能随功能或法规要求更新本政策。更新后会修改本页的「最近更新」日期；重大变更时，会尽量在站点首页或其他显眼位置提示。

8. 联系方式

如对本政策有疑问，请通过 GitHub 用户 shanxz1982 与站点维护者联系。也可先阅读 关于本站 / 常见问题。
